# SillyTavern Cloud Backup

将 SillyTavern 的角色卡、聊天记录、用户人设、预设、美化、世界书和 API 配置备份到 WebDAV 网盘，支持选择范围、自动上传和文件加密。

安装后，在酒馆的「扩展」页面打开 **酒馆云备份**。

## 安装与更新

仓库：[ZZZa-o/sillytavern-cloud-backup](https://github.com/ZZZa-o/sillytavern-cloud-backup)

**前端扩展和服务端插件都要安装，完成后重启 SillyTavern。**

### 一键安装（推荐）

在 SillyTavern 目录中，用 Bash 运行：

```bash
bash <(curl -sL https://cdn.jsdelivr.net/gh/ZZZa-o/sillytavern-cloud-backup@main/install.sh)
```

- **安卓 Termux**：先执行 `pkg install git curl`。
- **Linux / macOS**：需已安装 Git、curl 和 Bash。
- **Windows**：安装 Git for Windows 后，在酒馆目录右键打开 **Git Bash Here**，执行同一条命令；也可按下方步骤手动安装。

脚本会安装两部分、备份并更新 `config.yaml` 中的 `enableServerPlugins` 设置。**以后再次运行同一条命令即可更新，更新后重启酒馆。**

找不到酒馆目录时，在命令末尾加上实际路径，例如：

```bash
bash <(curl -sL https://cdn.jsdelivr.net/gh/ZZZa-o/sillytavern-cloud-backup@main/install.sh) ~/SillyTavern
```

### 手动安装

1. 下载并解压本仓库，将整个项目文件夹放到 `SillyTavern/public/scripts/extensions/third-party/sillytavern-cloud-backup/`。
2. 将项目里的 `server/` 和 `package.json` 复制到 `SillyTavern/plugins/sillytavern-cloud-backup/`。确认该目录下有 `package.json` 和 `server/index.js`。
3. 在酒馆的 `config.yaml` 中设置：

   ```yaml
   enableServerPlugins: true
   ```

4. 重启 SillyTavern。手动安装的更新方式是重新复制上述文件，再重启。

### Docker / NAS

1. 确认容器将宿主机的 `plugins/` 目录挂载到 `/home/node/app/plugins`，并保留现有的 `config/`、`data/` 挂载。
2. 在宿主机执行安装命令，末尾填写包含这些目录的实际路径：

   ```bash
   bash <(curl -sL https://cdn.jsdelivr.net/gh/ZZZa-o/sillytavern-cloud-backup@main/install.sh) /volume1/docker/sillytavern
   ```

3. 核对脚本输出的安装路径，确认宿主机的 `config/config.yaml` 中为 `enableServerPlugins: true`，然后重启容器。

没有 Git 时，可将完整仓库解压到宿主机的 `plugins/sillytavern-cloud-backup/`，在酒馆「扩展」页面用仓库链接安装前端，再完成配置和重启。

VPS 上直接运行的 SillyTavern 按一键安装操作；使用 Docker 的按本节操作。

## 首次使用

1. 打开「扩展 → 酒馆云备份」，确认显示 **后端已连接**。
2. 填写 **WebDAV 地址、用户名、授权密码、远端目录**。远端目录默认是 `sillytavern-backup`。
3. 点 **保存配置**，再点 **测试连接**。
4. 点 **范围**，勾选要备份的内容并确认。首次安装默认未选择任何内容。
5. 查看备份区自动显示的变更清单，再点 **上传到云端**。

WebDAV 授权密码保存后不回显，密码框留空会保留原密码；修改时填入新密码再保存。

## 选择备份范围

| 类别 | 可选内容 |
| --- | --- |
| 角色卡 | 逐张勾选；展开角色可选择具体聊天，或用「含聊天记录」包含所选角色的全部聊天 |
| 用户人设 | 逐个人设选择，包含名字、描述、注入设置与头像 |
| 预设 | 逐个选择 OpenAI 预设、快速回复 |
| 美化 | 逐个选择 UI 主题；背景图按整类选择，仅包含用户上传的图片 |
| 世界书 | 选择独立世界书；已内嵌的世界书随角色卡备份 |
| API 配置 | 逐个选择连接配置档，包含其引用的 API 密钥与代理密码 |

- 选「全选」后，新增内容也会自动纳入；需要固定范围时选择具体条目。
- 聊天记录随已选角色备份；「含聊天记录」全选模式也包含群聊和群组。
- 角色卡仅引用、未内嵌的世界书需要单独勾选。
- 二级菜单的「确定 / 取消」返回分类页；在分类页点「确定」保存本次选择，点「取消」放弃本次修改。

## 上传、恢复与云端文件

| 操作 | 结果 |
| --- | --- |
| **预览变更** | 立即重新比对两端，列出可上传、可下载的文件 |
| **上传到云端** | 上传范围内的本机文件，跳过内容相同的文件，保留云端其他文件 |
| **从云端下载** | 下载范围内的云端文件，覆盖本机同名文件 |

修改并保存本地内容后，备份区会自动更新「本地可更新」范围和文件清单；关闭自动上传时也会检查。点 **预览变更** 可立即重新读取云端并比对。

**下载覆盖不保留旧副本。** 用户人设和 API 配置按所选条目合并，本机独有的条目会保留。操作前可先预览。

「云端文件」区域可浏览全部备份，不受备份范围限制：点 **刷新** 加载，搜索名称或点 **当前** 筛选当前角色，用 **按路径 / 按时间** 切换排序，勾选后点 **下载** 或 **删除**。删除云端文件不可撤销。

搜索框右侧的两个图标分别为 **全选当前筛选结果** 和 **取消全部选择**：全选包含收起分组里的匹配文件，取消选择会清空被搜索隐藏的勾选。图标在宽屏第二行、窄屏第三行，悬停可查看说明。

列表将 **预设 / QR（快速回复）**、**美化 / 背景图片** 分别显示为同级文件夹，沿用原有网盘路径；浏览文件时，当前文件夹标题会吸顶。

角色卡标题最右侧的 **🔗 联动开关** 默认开启，选中角色卡时会一起选中它的聊天；人设会连同头像一起下载。

换设备接续聊天：在原设备上传，在另一台设备连接同一远端目录，刷新云端列表，下载对应的角色卡和聊天，再打开「管理聊天文件」。

大多数内容下载后立即显示；**快速回复和 API 配置需要刷新页面**，其他内容按完成提示操作。

## 多个方案与自动上传

- **方案**：可新建、切换、重命名或删除多套 WebDAV 配置。地址、密码、远端目录和加密设置分别保存；备份范围与自动上传设置共用。删除方案仅删除本机配置，保留云端文件。
- **自动上传**：默认关闭，开启后按设定间隔上传；默认 360 分钟，最短 15 分钟。可同时开启「聊天变化后检查」，设置修改后自动保存。
- 自动上传区域保留最近 5 次有文件上传或失败的记录，可展开查看文件名；刷新页面后仍可查看。
- 自动任务只上传；生成回复期间暂停上传。切到后台或关闭页面时尝试保存本地聊天，云端上传在后续检查时执行。

## 文件加密与配置保存

默认上传原文件。需要加密时，勾选 **加密上传的文件**，填写 **加密口令**，点 **保存配置**。每个方案单独设置。

- **请妥善保存口令；丢失后无法恢复加密备份。跨设备使用同一远端目录时，必须填写相同口令。**
- 加密口令会在面板中显示。WebDAV 密码和加密口令保存在本机用户目录的 `.sillytavern-cloud-backup/config.json`，更新插件会保留配置。
- 加密仅保护文件内容，文件名、大小和修改时间仍可见；加密文件需通过本插件下载使用。
- 开启加密后，之前上传且内容未变的文件不会自动重传。确认本机文件完整后，可在「云端文件」中删除对应旧文件，再重新上传；保留「插件元数据」分组。
- **API 配置备份包含所选配置引用的密钥和代理密码，建议同时开启加密。**

备份数据上传到你填写的 WebDAV 地址。

## WebDAV 配置参考

| 服务 | 填写提示 |
| --- | --- |
| 坚果云 | 使用服务商提供的 WebDAV 地址、账号和应用授权密码，见[官方设置教程](https://help.jianguoyun.com/?p=2064) |
| Koofr | 地址为 `https://app.koofr.net/dav/Koofr`，用户名填完整邮箱；在 Preferences → Password → App passwords 中生成应用密码 |
| InfiniCLOUD / NAS / Nextcloud / ownCloud / Cloudreve | 使用服务端提供的 WebDAV 地址和对应凭据 |

坚果云和 Koofr 均需应用授权密码。Koofr 地址中的 `Koofr` 大小写要保持一致。

## 常见问题

**显示「后端未加载」**

重启酒馆，检查 `enableServerPlugins: true`，以及 `plugins/sillytavern-cloud-backup/` 下的 `package.json` 和 `server/index.js`。Docker 用户同时检查插件目录挂载及宿主机配置文件；仍有问题时查看酒馆启动日志。

**测试连接或备份失败**

检查 WebDAV 地址、用户名、授权密码、远端目录的读写权限和网络连接。`401` 通常与凭据有关，`404` 可先检查地址和目录。

**世界书列表少了几本**

已内嵌在角色卡里的世界书随角色卡备份，独立世界书列表会显示隐藏数量。

**本机删了文件，云端还在**

上传会保留云端已有文件，需要清理时在「云端文件」中勾选并删除。
